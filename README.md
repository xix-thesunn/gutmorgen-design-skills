# Gutmorgen Design Skills

Скиллы для дизайнеров в Codex. Сейчас доступен **`$do-pages`** для сборки и обновления каруселей в Figma через Higgsfield.

## Пробная установка из main

Открой новый локальный чат Codex в настольном приложении и отправь:

> Установи только `$do-pages` через встроенный Skill Installer с параметрами `--repo xix-thesunn/gutmorgen-design-skills --ref main --path .agents/skills/do-pages --method download`. Выполни прямой запрос к GitHub. Если скачивание не удаётся, сообщи точную ошибку. Не запускай веб-поиск и не меняй репозиторий.

После установки попроси Codex проверить Higgsfield MCP и Figma MCP Bridge по разделу «Подключи зависимости» в [INSTALL.md](https://raw.githubusercontent.com/xix-thesunn/gutmorgen-design-skills/main/INSTALL.md). Если потребуется, войди в Higgsfield и запусти Bridge в нужном файле Figma Desktop. Затем открой новый чат и вызови `$do-pages`.

## Командная установка из релиза

Этот вариант станет доступен после публикации первого релиза. Отправь в локальный чат Codex:

> Установи Gutmorgen Design Skills из https://github.com/xix-thesunn/gutmorgen-design-skills. Прочитай https://raw.githubusercontent.com/xix-thesunn/gutmorgen-design-skills/main/INSTALL.md напрямую и следуй инструкции. Если источник или релиз недоступен, сообщи ошибку.

Для скачивания скиллов из публичного репозитория дизайнеру достаточно доступа к GitHub по сети. Git и аккаунт GitHub для этого не нужны.

## Как обновить подборку из релиза

- **«Проверь обновления Gutmorgen Design Skills из xix-thesunn/gutmorgen-design-skills»** — покажет, какие скиллы появились и что изменилось.
- **«Обнови Gutmorgen Design Skills из xix-thesunn/gutmorgen-design-skills»** — обновит установленные скиллы подборки, добавит новые и кратко перечислит изменения.
