# Design Skills

Скиллы для дизайнеров в Codex. Сейчас в подборке есть **`$do-pages`** для сборки и обновления каруселей маркетплейсов в Figma через Higgsfield.

## Как установить

1. Открой **Codex в настольном приложении ChatGPT** и начни локальный чат.
2. Вставь ссылку на этот репозиторий и отправь сообщение:

   > Установи дизайн-скиллы из <ссылка на этот репозиторий GitHub>. Возьми последний опубликованный релиз и выполни INSTALL.md. Помоги подключить зависимости и проверь их.

3. Если Codex попросит, войди в Higgsfield. В Figma Desktop импортируй плагин Bridge по подсказке Codex и запусти его в рабочем файле.
4. После установки открой новый локальный чат и вызови `$do-pages`.

Для установки из релиза публичного репозитория достаточно доступа к GitHub по сети. Git и аккаунт GitHub дизайнеру не требуются.

## Как обновить

- **«Проверь обновления дизайн-скиллов из <ссылка>»** — покажет новые скиллы и что изменилось.
- **«Обнови дизайн-скиллы из <ссылка>»** — установит новые скиллы, обновит текущие и кратко перечислит изменения.
